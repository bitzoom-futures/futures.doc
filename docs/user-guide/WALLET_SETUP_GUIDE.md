# Bitzoom Wallet Testing Guide

Your complete guide to setting up a test wallet for testing deposit and withdrawal on Bitzoom.

### Step 1 &mdash; Install TronLink Wallet

Install the TronLink browser extension from the Chrome Web Store:

**https://chromewebstore.google.com/detail/tronlink/ibnejdfjmmkpcnlpebklmnkoeoihofec**

1. Open the link above in Chrome
2. Click **Add to Chrome** to install the extension
3. Click the **puzzle icon** in the top-right corner of Chrome and pin TronLink for easy access

### Step 2 &mdash; Create a Wallet

After installing TronLink, open the extension and create a new wallet.

1. Click the **TronLink icon** in the Chrome toolbar
2. Select **Create Wallet**
3. Set a **wallet name** and **password**
4. **Back up your seed phrase** &mdash; write it down and store it safely
5. Confirm the seed phrase to complete setup

### Step 3 &mdash; Your Wallet is Ready

After creating your wallet, you will see the main wallet screen.

1. Check the **top-right corner** &mdash; it should show **GasFree**
2. Your wallet is now created with **$0** balance
3. You will see a **Security Alert** warning you to back up your wallet
4. Click **Back up** to proceed to the backup step

### Step 4 &mdash; Back Up Your Wallet

Back up your seed phrase to keep your wallet safe.

1. Click **Back up** from the security alert or go to Settings to back up
2. Write down your **seed phrase** on paper and store it safely
3. **Never share** your seed phrase with anyone
4. Confirm the seed phrase to complete the backup

### Step 5 &mdash; Enable Test Networks

By default, TronLink only shows the Mainnet. You need to enable test networks first.

1. Open TronLink and click the **Settings icon** (gear) in the top-right corner
2. Choose **Network**
3. Toggle on **Show test network**
4. Go back to the main screen

### Step 6 &mdash; Switch to Nile Testnet

Now switch the active network to the Nile Testnet.

1. On the main screen, click the **network icon** (next to the Settings gear icon) in the top-right corner
2. Select **Nile Testnet** from the list
3. You should see the network label change to confirm you are on the testnet

You will need your wallet address to receive test tokens.

### Step 8 &mdash; Get Test TRX (Gas)

TRX is needed to pay for transaction fees (gas) on the TRON network. Visit the Nile Testnet faucet to get free test TRX.

**https://nileex.io/join/getJoinPage**

1. Open the faucet link above
2. Find the **"Get 2000 test coins"** section
3. Paste your **wallet address** into the Account Address field
4. Complete the **reCAPTCHA** verification
5. Click **Obtain** to receive 2000 test TRX
